# Buzdolabı Işık Mahkemesi

> Resmi slogan: Kapı kapanınca hukuk başlar.

Bu depo, insanlığın çözemediği tek anayasal krizi çözer: buzdolabı ışığı, kapı kapanınca gerçekten sönüyor mu, yoksa biz bakmazken mini bir diskoya mı dönüyor?

Proje ciddidir. Ciddi değildir. İkisi aynı anda, aynı rafta, sütün arkasında.

## Ne işe yarar

`mahkeme.py` şunları yapar:

1. Sanık lambayı tutuklar (metafizik olarak).
2. Tanık listesini yoğurt, maydanoz ve gece 03:12'deki sen olarak doldurur.
3. Delil olarak kapı contığının gıcırtısını dinler.
4. Karar verir. Karar her seferinde farklıdır çünkü içtihat buzludur.

## Kurulum

Python 3 yeter. Bağımlılık yok. Elektrik faturası ayrıca.

```bash
python3 mahkeme.py
python3 mahkeme.py --iddia "isik sondugunu iddia ediyor ama peynir tersini soyluyor"
```

## Mahkeme heyeti

| Makam | Kişi | Yetki |
| --- | --- | --- |
| Başkan | Kapı contığı | Gıcırdama ile veto |
| Üye | Yarım limon | Ekşi muhalefet şerhi |
| Katip | Buz kalıbı | Tutanak erir |
